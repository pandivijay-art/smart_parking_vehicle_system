# smart_parking_vehicle_system

## Smart Parking Management System 

### A simple Python project for managing vehicle parking.

## Features

- Vehicle type selection
- Normal & Premium parking
- Parking duration and fee calculation
- Parking slot allocation
- Parking receipt generation
- Basic input validation

## Technologies

- Python
- Jupyter Notebook

## Concepts Used

- Variables
- Input & Output
- If-elif-else
- Lists
- Operators
- Boolean validation
